# Library-Management-System-C-OOP-
Library Management System built in C++ using Object-Oriented Programming
Features

1.    Add a new book to the library.
2.    Remove a book by ISBN.
3.    Borrow a book (mark it as unavailable).
4.    Return a book (mark it as available).
5.    Display all books in the library.
6.    Basic error handling (e.g., duplicate ISBNs, ISBN not found).

book.h: Defines the Book class, which stores details like title, author, ISBN, and availability.
library.h and library.cpp: Define the Library class, which manages a collection of books using a std::vector.
main.cpp: Contains the main function to demonstrate the library’s functionality.
